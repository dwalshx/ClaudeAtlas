# Phase 3.3 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> Derived from `3.3-RESEARCH.md` § Validation Architecture.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | node:test (`node --test`), Node 20 (CI) / 22 (local) |
| **Config file** | none — glob in package.json (`scripts/**/*.test.js`) |
| **Quick run command** | `node --test scripts/__tests__/<file>.test.js` |
| **Full suite command** | `npm test` (= `node --test "scripts/**/*.test.js"`) |
| **Pattern lint** | `npm run check:patterns` (must stay green) |
| **Build gate** | `npm run build` + `npm run postbuild` (page-count + sitemap completeness) |
| **Estimated runtime** | ~30–90s unit suite; build is the slow gate |

**Test-location note (research-flagged):** the test glob is `scripts/**/*.test.js`. A
`src/lib/plugins.test.js` would NOT be picked up — place loader tests under
`scripts/__tests__/` OR widen the glob. Planner must resolve this in Wave 0.

---

## Sampling Rate

- **After every task commit:** `node --test <changed test file>` + `npm run check:patterns`
- **After every plan wave:** `npm test` + `npm run build` (page-count + sitemap gates)
- **Before `/gsd:verify-work`:** full suite green + build green, THEN the human-gated
  bootstrap dispatch + flag flip + first-warm-cron observation (mirrors 3.2.1's phase-gate
  validation run — NOT locally runnable; wrangler/worker/dispatch are CI/UI-only)
- **Max feedback latency:** ~90s (unit); build gate slower; pipeline observation is CI/human
