## Decisions Made

- **Display-only category chips** (Claude's discretion per plan): `/category/<slug>/` pages list skills only, so plugin chips link nowhere rather than misleading users; chip labels derive from `category:<slug>` tags via an 8-entry slug→label map with title-case fallback.
- **`data-search-endpoint` attribute pattern**: Astro/Vite bundles page scripts into hashed `_astro/*.js` assets, so the `type=plugin` string would not appear in the static HTML. Carrying the endpoint on the input element keeps the wiring greppable/visible in HTML and is the configuration-over-hardcoding shape.
- **Tolerance on combined basis**: `computeTolerance(skillCount + pluginCount + mcpCount)` rather than skills-only — keeps the 15% creator-page scaling term proportional to the full catalog.
