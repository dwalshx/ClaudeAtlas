<objective>
Cut Track 2 discovery cost so the daily GitHub Actions pipeline finishes
end-to-end in under 30 minutes, reliably, with the 3.0.1 architecture
preserved. Six consecutive daily runs (4/30 → 5/5) have hit the 90-minute
job timeout because the per-skill loop re-fetches every SKILL.md body on
every run regardless of whether content changed. The single-line, 24h
scraped_at age check at scripts/scrape-discover-repos.js:317-321 turns into
a 100% cache miss after the first run.

content-derived blob SHA comparison (the trees endpoint already gives us
the sha for free), cap per-repo SKILL.md count at 50 to keep mega-repos
from monopolizing rate budget, and document the residual Track 1 daily
etag-invalidation cost so future maintainers know it is intentional.

Purpose: unblock daily convergence — fresh history snapshots, refreshed
engagement signals, new content discovered within 3 days of push — and
unblock Phase 3.1.
