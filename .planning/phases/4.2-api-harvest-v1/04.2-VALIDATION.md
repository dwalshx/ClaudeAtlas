## Sampling Rate

- **After every task commit:** the task's own test file(s) via `node --test <file>` + `npm run check:patterns`
- **After every plan wave:** `npm test` + both lints (expected `# fail` per the red/green schedule above)
- **Before `/gsd:verify-work`:** full suite at baseline + N, lints clean, `git diff --stat 2b0bc8b...HEAD -- scripts/filter.js scripts/score.js` empty, `git status` shows no `data/apis*`, `data/api-vectors*` or `data/feeds-etag-cache.*`
- **Max feedback latency:** 10 seconds
