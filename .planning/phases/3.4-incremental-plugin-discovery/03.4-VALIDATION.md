## Sampling Rate

- **After every task commit:** `node --test scripts/__tests__/scrape-plugins.test.js` + `npm run check:patterns`
- **After every plan wave:** `npm test`
- **Before `/gsd:verify-work`:** full suite green
- **Phase gate:** full suite green → branch dispatch measurement (R-1/R-5/R-6) → human flag-flip on main → first-warm-cron observation (R-8). Mirrors 3.2.1's CI/UI-only phase-gate run (wrangler/workflow-dispatch not locally runnable).
- **Max feedback latency:** ~5 seconds (unit); branch/cron checkpoints are async (hours)
