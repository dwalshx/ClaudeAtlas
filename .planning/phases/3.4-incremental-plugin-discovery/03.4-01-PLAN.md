<objective>
Fix the cross-run skip-wiring bug (Change A — the MANDATORY budget fix) and lay
the Wave 0 test scaffold the rest of the phase builds on.

Root cause (RESEARCH §A / Pitfall 1, verified): `loadCheckpoint()`
(scrape-plugins.js:318) reads only `PARTIAL_PATH`
(`data/plugins-raw.ndjson.partial`), but the GHA cache + bootstrap release only
persist the OUTPUT `data/plugins-raw.ndjson`. The `.partial` never survives
between runs, so `processedSet` starts empty every run, the line-363 skip never
fires, and all ~7,300 repos are re-walked from cold → ~24h → timeout. The
restored OUTPUT corpus (all walked repos) is silently ignored.

Fix: seed `processedSet` from the cached OUTPUT, merging `.partial` for same-job
resume. This alone collapses the warm walk from ~7,300 repos to the daily
new-repo delta.

Purpose: Make a warm daily plugin run fit the budget. This is the foundation —
Plans 02 (B) and 03 (C) layer freshness + completeness on top.
Output: A corrected `loadCheckpoint()` + an R-2 regression test that would have
caught the original bug.
</objective>
