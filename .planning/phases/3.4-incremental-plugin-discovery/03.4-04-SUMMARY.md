## Deviations / learnings

1. **Measure-before-flip caught a real risk** (the Sunday full re-walk thin margin)
   → the 3.4-05 weekly split. The discipline paid off exactly as intended.
2. **GHA cache is branch-scoped** — a steady-state branch run can't see a stamped
   cache created on a different branch; it restores the unstamped bootstrap and
   does a one-time cold backfill (~4h plugin / ~324 min total, still under cap).
   On main, the weekly workflow seeds the stamped cache so daily runs are
   steady-state. Documented for future re-measurements.
3. Steady-state total is ~2.5h (not the ~90 min first estimated) — the daily
   GraphQL refresh of all known repos is the recurring cost. Well under budget.
