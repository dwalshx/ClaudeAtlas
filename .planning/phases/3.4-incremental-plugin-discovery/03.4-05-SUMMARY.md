**Moved the plugin full re-walk out of the daily cron into a dedicated weekly workflow (Sundays 02:00 UTC, own 360-min budget) that feeds the daily cron via the shared `plugins-raw-ndjson-` GHA cache prefix; the daily path is now env-gated steady-state delta only.**

## Decisions Made
- **Env-only trigger helper:** `isFullRewalk` strips the non-deterministic `Date` dependency from the gate, making it injectable/testable and ensuring the daily path can never auto-trigger a full re-walk by day-of-week.
- **Reuse the existing cache prefix:** the weekly workflow saves under `plugins-raw-ndjson-` (the prefix the daily cron's `restore-keys` already matches), so the handoff needed zero changes to daily-scrape.yml.
- **Lean weekly workflow:** corpus-refresh + cache-save only; the daily cron stays the sole publisher.
- **Sundays 02:00 UTC:** finishes before the 06:30 UTC daily cron picks up the fresh corpus.
