## Decisions Made

- **Exact verification strengthened into ann.js itself** (per plan's deliberate design): the hnsw path recomputes `sim = dot(...)` for every searchKnn candidate and discards the index's `1 - distance` — parity test asserts exact float equality, false dedup merges from drift are impossible
- **efSearch floor of `kk + 1`** applied in the hnsw path (`setEf(Math.max(efSearch, kk + 1))`) so tiny-k calls can never under-search below the requested neighbor count
- Near-duplicate fixture perturbation set to 0.02/dim (sim ≈ 0.996) so the planted pairs clear the 0.98 ip-sign assertion with margin
