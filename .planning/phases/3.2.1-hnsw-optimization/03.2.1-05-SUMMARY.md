## Accomplishments

- **scripts/validate-ann-recall.js (326 lines):** hard-requires `annEngine() === 'hnsw'` (FATAL exit 1 on the exact fallback — verified live on the dev box), loads vectors via `readNdjsonRecords` keyed by `r.id`, single O(n²) exact pass collects the true >0.92 pair set + per-item top-1 sims + bounded top-K lists (insertion mirrors ann.js tie-breaking: sim DESC, idx ASC), then `topKNeighbors(items, kDup, { efSearch, engine: 'hnsw' })` derives the symmetrized ANN pair set. Emits machine-greppable `[validate-ann]` metric lines and `RESULT=PASS|FAIL` with matching exit codes.
- **Four locked gates implemented with literal thresholds:** pair_recall ≥ 0.995, dup_flap < 0.005 (stack-based BFS cluster membership, same shape as enrich.js), topk_overlap ≥ 0.95 (K=3 default), novelty_jaccard ≥ 0.95 (top-5% sets by 1 − top-1 sim). Plus the misses-only invariant: any ANN pair absent from the exact set fails the run regardless of recall.
- **Engine gates closed (RESEARCH.md Pitfall 2):** enrich and Build steps now `set -o pipefail` + tee to `/tmp/enrich.log` / `/tmp/build.log`; two non-push gate steps grep the literal `[ann] engine=hnsw` and fail with `::error::` if the exact fallback ran — the silent O(N²) cron regression path is closed.
- **Timing gates:** both gates parse the load-bearing elapsed log lines (`enrichment complete in <N>s`, `similar-skill sets in <N>s`), fail if ELAPSED parses empty, and enforce `< 900` seconds via awk.
- **Push-event deploys unaffected:** all new gates are `github.event_name != 'push'`; the validation step requires `workflow_dispatch && inputs.validate_ann == 'true'`; `timeout-minutes: 360`, PLUGINS_ENABLED gate, and all main-only conditions untouched.

## Decisions Made

- Validation harness gets the codebase-standard `invokedAsScript` guard (enrich.js/compute-similar.js pattern) so the plan's import-check verify passes cleanly without executing the engine FATAL on the dev box
- `annTop1` symmetrized to mirror enrich.js's `nnSim[j]` update; `annTopK` left unsymmetrized to mirror compute-similar.js — each metric validates its actual production consumer's semantics
- topk_overlap divides by `min(topK, n-1)` so tiny fixtures don't fail vacuously (identical to `/topK` at production n)
- Reworded a harness comment that contained the literal string "readFileSync" so the acceptance criterion `grep -c "readFileSync" == 0` holds (the code never called it — chunked NDJSON helper throughout)
