  <action>
    New script, node-invocable: `node scripts/validate-ann-recall.js [--input data/skill-vectors.ndjson] [--threshold 0.92] [--k-dup 64] [--ef-search 150] [--top-k 3]`. All logging prefixed `[validate-ann]`.

    Flow:
    1. Hard-require the native engine: `if (annEngine() !== 'hnsw') { console.error('[validate-ann] FATAL: hnsw engine unavailable — validation is meaningless on the exact fallback'); process.exit(1); }`
    2. Load vectors via `readNdjsonRecords(inputPath, { keyFn: r => r.id })` (NDJSON helper — NEVER readFileSync on data/). Normalize each `values` to Float32Array via normalizeFloat32; build items sorted by id. Log n and warn (but proceed) if n < 10000 (cold cache → results not representative).
    3. EXACT BASELINE — one O(n²) i<j pass over the Float32 vectors using dot() (~35-65 min at 51k on the 4-vCPU runner; log progress every 1000 rows with elapsed). In the single pass collect:
       - `exactPairs`: Set of `i*n+j` keys for every pair with sim > threshold (the true 0.92 pair set)
       - `exactTop1[i]`: max sim per item (novelty input)
       - `exactTopK[i]`: per-item top-`top-k` neighbor idx lists (bounded insertion, K=3)
    4. ANN CANDIDATES — `topKNeighbors(items, kDup, { efSearch, engine: 'hnsw' })`; derive:
       - `annPairs`: Set of i<j keys where any returned candidate sim > threshold (symmetrized — either side finding it counts)
       - `annTop1[i]`, `annTopK[i]` (first top-k entries)
    5. METRICS + GATES (locked thresholds):
       - `pair_recall = |annPairs ∩ exactPairs| / |exactPairs|` — gate ≥ 0.995. Also assert `annPairs ⊆ exactPairs` (misses-only invariant; any extra pair = exact-verification bug → FAIL regardless of recall).
       - `dup_flap`: BFS-cluster both edge sets (same stack-based BFS as enrich.js); boolean per item "is in a cluster of size ≥ 2"; flap = fraction of items whose boolean differs — gate < 0.005.
       - `topk_overlap`: mean over items of |annTopK[i] ∩ exactTopK[i]| / top-k — gate ≥ 0.95.
       - `novelty_jaccard`: novelty rank = 1 - top1 sim; take the top-5% item sets by novelty under both paths; Jaccard(setA, setB) — gate ≥ 0.95.
    6. Output — one line per metric, machine-greppable, then a final verdict:
       ```
       [validate-ann] n=51234 engine=hnsw k_dup=64 ef_search=150 threshold=0.92
       [validate-ann] pair_recall=0.9991 gate>=0.995 PASS
       [validate-ann] dup_flap=0.0012 gate<0.005 PASS
       [validate-ann] topk_overlap=0.9870 gate>=0.95 PASS
       [validate-ann] novelty_jaccard=0.9923 gate>=0.95 PASS
       [validate-ann] RESULT=PASS
       ```
       Exit 0 only if ALL gates pass; otherwise print `RESULT=FAIL` and exit 1.
    7. Memory: 51k × 1536 Float32 ≈ 313 MB + hnsw index ~330 MB off-heap — fine on the 16 GB runner; do not hold the float64 source arrays after normalization (null them out, Pitfall 7).
  </action>
