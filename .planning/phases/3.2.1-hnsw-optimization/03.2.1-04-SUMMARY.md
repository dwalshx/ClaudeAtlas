# Phase 3.2.1 Plan 04: compute-similar.js ann.js Rewrite Summary

**compute-similar.js now retrieves top-K via ann.js topKNeighbors (HNSW in CI, exact fallback locally) under a 7-test output-shape baseline that was green against the original naive O(n²) implementation first**

## Accomplishments

- **Wave-0 baseline lock honored:** `scripts/__tests__/compute-similar.test.js` (7 tests) was written and green against the CURRENT naive implementation, committed BEFORE the engine swap (`d6c6644` precedes `d1c406d` in git log) — compute-similar previously had zero tests.
- **Naive O(n²) kernel deleted:** local `cosineSimilarity()`, per-pair norm recomputation, and per-row 51k-object allocation + full sort are gone; replaced with `normalizeFloat32` + `topKNeighbors(items, topK)` from `scripts/lib/ann.js`. Build-step long-pole projected ~162 min → ~3-5 min at 51k.
- **Pure `computeSimilar(records, topK)` export** + `invokedAsScript` guard (verbatim enrich.js pattern) — module is import-safe for tests; `main()` only runs as a script.
- **Pitfall 7 memory shape:** float64 `values` refs nulled immediately after Float32 normalization, so the 51k run never holds both copies alongside the Astro build.
- **Contracts preserved:** `TOP_K = 3` unchanged; `computed N similar-skill sets in Ns` log line verbatim (Plan 05 timing gate parses it); push-event stale-1,078-vector-seed behavior untouched (RESEARCH Pattern 3 — preserved deliberately).

## Decisions Made

- Shape tests are engine-agnostic by construction: fixture slug order equals input order so naive stable-sort and ann.js idx-ascending tie-breaking select identical neighbors; exact score assertions limited to float-unambiguous values (0, 0.5, 1/√2→0.7071, 1.0) that round identically from float64 cosine and Float32 dot.
- `computeSimilar()` documented as destructive on input (`rec.values = null` per Pitfall 7); the determinism test builds a fresh fixture per call.
- Output-object key order moved quality-sorted → slug-sorted (ann.js caller-sort determinism contract). Shape-neutral: consumers (`src/lib/skills.js`) look up by slug key.
