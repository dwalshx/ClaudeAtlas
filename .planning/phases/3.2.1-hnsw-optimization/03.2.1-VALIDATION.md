## Sampling Rate

- **After every task commit:** Run targeted `node --test <changed-area tests>` + `npm run check:patterns`

- **Before `/gsd:verify-work`:** Full suite green + CI real-vector recall validation green + one full branch-dispatch cron observed with `engine=hnsw` and timing gates passing
- **Max feedback latency:** ~90 seconds (local); real-recall validation is CI-only (needs warm `skill-vectors-*` GHA cache — local vector file is the stale 1,078-record seed)
