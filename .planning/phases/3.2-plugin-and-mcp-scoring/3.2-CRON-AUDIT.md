## Step 3 — Mitigation decision

The plan's default was **Option D + Option C**. The B-3 caveat explicitly
required verifying Option C's savings against the actual code rather than the
naive 30% expectation. That verification follows.

**Option C (reduce compute-similar `TOP_K` 5 → 3) — verified to save ~0 min of
compute.** `scripts/compute-similar.js` is O(n²): for every record it cosine-
scores against *every other* record (the dominant cost), then `sort`s the full
score list, then `.slice(0, TOP_K)`. `TOP_K` only bounds the *retained output
list size* and the trailing `.map` — it does **not** reduce the O(n²) cosine
scan or the per-row full sort. So K=5→3 yields a negligible runtime delta (it
only shrinks the `similar-skills.json` sidecar by ~40% and trims a tiny `.map`).
The Rev 1 skeleton's "-18 min (K=5→3, 30% less)" figure does not hold against
the real code. **Recorded honestly: Option C mitigation Δ = 0 min.**

**enrich.js has no `K` at all.** Its dedup is a brute-force O(n²) cosine with a
fixed `DUP_THRESHOLD = 0.92` and BFS clustering — there is no top-K neighbor
search to shrink. So the plan's "Enrich skills -3 (K=5→3)" row is also
inapplicable; enrich stays at its measured ~33 min.

**Option D (bump `timeout-minutes` 300 → 330) is the operative mitigation.**
With the honest projection at ~293 min, Option D alone clears the 320-min gate
with a 37-min margin and a 27-min margin under the hard 330-min ceiling. The
2026-05-30 timeout happened against the *old 300-min* ceiling — raising to 330
(GHA cap is 6h/360 min) restores headroom even after the +48 min of plugin/MCP
work.

**Escalation check (B-3):** post-mitigation total ~293 min ≤ 320 min →
**no escalation to Option B required.** Option B (split plugin discovery to a
weekly `weekly-plugin-discover.yml`) remains documented as the next lever if a
future phase pushes the projection past 320 (most likely cause: Build/embed
growth as the catalog scales, or Track 2 variance spikes).

**Selected mitigation: Option D (timeout → 330).** Option C is applied anyway as
a zero-risk output-size reduction (smaller `similar-skills.json`), but is *not*
counted toward the time budget — its compute savings are ~0 as shown above.
