## Decisions Made

- **content_sha cache preservation (Task 9, Rule 1).** The plan literally said delta-detection should be "based on `buildEmbeddingInput(record)` output," but the legacy `computeContentSha` hashes a different pipe-joined string than what is embedded. Switching would invalidate all ~35k prior skill `_content_sha` values → 0% cache hit → B-2 guard fires → ~$0.22 re-embed every run. Kept the legacy pipe-join formula for skills (preserves 100% cache hit, the actual must-have), used registry text only for new plugin/mcp types. Documented inline.
- **Option C (TOP_K 5→3) is not a compute mitigation (Task 13).** Verified against `compute-similar.js`: TOP_K only bounds the retained output slice, not the O(n²) cosine scan or the per-row sort. enrich.js has no K at all (fixed-threshold BFS dedup). Recorded Δ=0 honestly in the audit; the operative mitigation is the timeout bump (Option D). Build Astro (~94 min mean) is the real binding cost surface, not embed/enrich.
- **gitignore plugins/mcp NDJSON + vectors.** They're rebuilt each cron run (mirrors skills.ndjson); committing them would bloat the repo and risk the F1 commit-back footgun. Only the bounded `pipeline-stats.json` sections are committed.
