## Sampling Rate

- **After every task commit:** Run the task's own test file(s) via `node --test <file>` + `npm run check:patterns`
- **After every plan wave:** Run `npm test` + both lints; confirm `fail 2` and `5 legacy-shape hit(s)`
- **Before `/gsd:verify-work`:** Full suite green at baseline, `check:patterns` clean, `git diff --stat` touches no `scripts/filter.js` calibration constants
- **Max feedback latency:** 10 seconds
