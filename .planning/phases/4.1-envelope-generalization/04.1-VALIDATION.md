## Sampling Rate

- **After every task commit:** Run the task's own test file(s) via `node --test <file>` + `npm run check:patterns`
- **After every plan wave:** Run `npm test` + both lints. Expected fail counts per wave: after wave 1 → 2 + 7 red files (expected; `workflow-flags` starts at pass 2 / fail 2, `common.rules` at pass 3 / fail 2); after wave 2 → red files shrink to round-trip + scorer/rules + workflow-flags; after wave 3 → round-trip (slug/tier/registry legs) + `workflow-flags` red; after wave 4 → only `workflow-flags` red (`fail 4` = 2 embed-skills + 2 workflow-flags); after wave 5 → `fail 2`. Legacy-shape lint is `5 legacy-shape hit(s)` after EVERY wave.
- **Before `/gsd:verify-work`:** Full suite green at baseline, `check:patterns` clean, `git diff --stat cbae842...HEAD -- scripts/filter.js scripts/score.js` empty
- **Max feedback latency:** 10 seconds
