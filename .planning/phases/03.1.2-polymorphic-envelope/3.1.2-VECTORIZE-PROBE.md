## What that means for downstream phases

- The worker filter triad `?tier`, `?category`, `?type` is live (T8). All
  three accept the documented values and assemble into Vectorize's
  `filter: { ... }` query object additively.

- `?type=skill` returns matches with `metadata.entity_type='skill'` — works
  the day plugins/MCPs land because new uploaders populate `entity_type`
  per their entity discriminator.

- Tag-array filtering (`filter: { tags: { $eq: 'category:foo' } }`) — NOT
  available. Categorical filtering uses the legacy `metadata.category`
  string field. This is the conservative branch (Outcome B in T8's
  branching logic).
