# Plan: Creators Browse Page (/creators/all/)

<objective>
Ship a single new route, `/creators/all/`, that renders every creator in the index in a sortable, filterable table. Persists state to URL query params so a view is shareable.
</objective>

<must_haves>
- Route `/creators/all/` generates at build time
- All 776 creators render into the DOM in a single table
- Columns sort on click (username, type, skills, featured, stars, quality, first commit)
- Default sort: Total Quality descending
- Sort direction indicator on the active column
- Free-text search on username (debounced 150 ms)
- 8 category chip filters (OR semantics — any selected category matches)
- Type toggle: All / Users / Orgs
- Result count updates live as filters change
- URL query params: q, sort, dir, cat, type — read on load, written on every change
- Clear-filters button appears when any filter is non-default
- Row click → navigate to /creators/[username]/
- Bidirectional link with /creators/ leaderboard (prominent button)
- Empty state when no creators match filters
- npm run build produces no errors, page count increases by 1 (1865 → 1866)
</must_haves>

<task id="01.5.1.1">
<action>
Add a small helper to `src/lib/skills.js` that serializes the full creator list for browse rendering. It trims fields down to what the browse page needs (keeps the page's JSON payload small) and returns a plain array ready to embed.

Insert this function after `getCreatorLeaderboards`:

```js
/**
 * Browse-page-friendly view of every creator. Omits heavy fields (the
 * `skills` array, the `categories` Set) and keeps only what the browse
 * table displays or filters on. Returned as a plain array sorted by
 * total_quality_score desc (default sort).
 */
export function getCreatorsForBrowse() {
  const creators = [...getCreators().values()];
  return creators
    .map(c => ({
      username: c.username,
      avatar_url: c.avatar_url,
      type: c.type,
      total_skills: c.total_skills,
      featured_count: c.tier_counts?.featured || 0,
      total_stars: c.total_stars,
      total_quality_score: c.total_quality_score,
      avg_quality_score_precise: c.avg_quality_score_precise,
      first_commit_at: c.first_commit_at,
      categories: c.categories, // already an array (set → array in getCreators)
    }))
    .sort((a, b) => (b.total_quality_score - a.total_quality_score) || (b.total_skills - a.total_skills));
}
```
</action>
