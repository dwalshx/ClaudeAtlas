# Phase quick-260603-e96 Plan 01: Fix Failing Daily Scrape (Track 1 Star Pulse) Summary

Track 1's per-repo REST refresh tripped GitHub's secondary (abuse) rate limit at ~4,351 back-to-back GETs; replaced with batched GraphQL (50-repo aliased queries) plus a retry-after-aware backoff stopgap, ending the daily-pipeline failures and protecting the unreplayable star-history snapshot.

## What Shipped

### Task 1 — Stopgap (commit c0902b7)
- `scripts/lib/github-fetch.js`: in BOTH `fetchWithETag` and `rateLimitedFetch`, the 403/429 branch now reads `retry-after` (the SECONDARY/abuse-limit signal) and honors it — capped at 120s + 1s jitter — BEFORE falling back to `x-ratelimit-reset` (PRIMARY) and then blind-60s. The prior code only read `x-ratelimit-reset`, so a secondary 403 caused an up-to-~1hr over-wait (blowing the 330-min ceiling) or a blind-60s immediate re-trip.
- `scripts/scrape-pulse.js`: `MAX_FAIL_RATIO` 0.10 → 0.15 (a partial secondary-limit blip should not drop the snapshot); added a ~100ms inter-request delay (`PULSE_DELAY_MS`) to the serial loop. (The delay was then superseded by the GraphQL inter-batch delay in Task 2.)

### Task 2 — GraphQL batch migration (commit e0ca2fa)
- New `scripts/lib/github-graphql.js` exporting:
  - `buildPulseQuery(repoFullNames)` — pure; builds an aliased `r0..rN: repository(owner,name){...}` query + `aliasMap`. owner/name split on first slash; defensive quote escaping.
  - `mapGraphqlRepoToFields(node)` — pure; emits exactly the 11 `TRACK1_FRESHNESS_FIELDS`. `repo_open_issues = issues(OPEN).totalCount + pullRequests(OPEN).totalCount` (D2 REST parity). Same `|| 0 / || false / || null / []` nullish defaults as the REST shape. Comment explicitly defers the issues-only semantic.
  - `fetchRepoBatchGraphql(repoFullNames)` — POSTs to `https://api.github.com/graphql` with `Bearer ${GITHUB_TOKEN}` (SCRAPE_PAT in CI). Tolerates null aliases (deleted/renamed/private → casualty), does NOT treat a non-empty `errors[]` as whole-query failure, only fails on transport non-200 or missing `data`. retry-after-aware 403/429 backoff via a LOCAL `sleep` — ZERO import from github-fetch.js (token-free guarantee).
- `scripts/scrape-pulse.js`: replaced the per-repo REST loop with 50-repo GraphQL batches (`BATCH_SIZE=50`, `BATCH_DELAY_MS=100`, ~88 serial batches for 4,351 repos). Removed the now-dead `refreshRepo` REST helper and the `fetchWithETag`/`getETagCache`/`saveETagCache` imports + ETag-persist calls (GraphQL has no 304/ETag path). The `freshByRepo` Map / `failures` array / apply-in-place loop / `writeHistorySnapshot` / data-file read+write paths are UNCHANGED.

### Task 3 — Unit tests (commit 921be94)
- New `scripts/lib/__tests__/github-graphql.test.js`: 7 `node:test` cases — exact 11-key parity, issues+PRs sum (D2, with anti-regression guard), nullish defaults, topics flattening, license spdxId→key→null fallback, query/aliasMap round-trip + first-slash split, null-alias casualty resolution. Token-free (no `GITHUB_TOKEN` set, no github-fetch.js import) and network-free (inline fixtures).
