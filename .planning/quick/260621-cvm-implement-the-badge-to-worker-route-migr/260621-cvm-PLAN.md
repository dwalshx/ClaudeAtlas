<objective>
Move per-skill badge SVGs off static-asset generation onto an on-demand Worker
route, eliminating ~18k local (~50k+ prod) static files. This halves the
Cloudflare deploy file count and clears the `assets-upload-session -> 504` that
is currently blocking ALL deploys (the nav change is stuck behind it).

`/badge/{slug}.svg` (tier pill) and `/badge/{slug}-history.svg` (star chart) are
generated per-request by the Worker. Tier data already lives in SKILLS_KV;
star-history is bundled into the Worker as a compact JSON map (like
slug-redirects.json). The SVG builder functions are pure (zero Node deps) and
are ported VERBATIM so output stays byte-identical.

Purpose: deploy reliability — unblock the deploy pipeline.
Output: new build-time data generator, new Worker badge module + route, prebuild
swap, the old generator deleted, and the bundle committed back daily.
</objective>
