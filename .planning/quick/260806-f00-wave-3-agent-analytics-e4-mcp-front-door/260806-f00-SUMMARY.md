## Marker-header design

`x-ca-mcp: 1` and `x-ca-mcp-client: <name>/<version>` are set by
worker/mcp.js on every response to a **structurally valid** JSON-RPC
envelope (including notifications' 202 and -32601/-32602 errors); the
-32700 parse-error and -32600 invalid-request paths do NOT set them, so
garbage POSTs to /mcp never classify as agents. They are intentionally
client-visible (harmless — the client sent that data) because the
waitUntil logger only has request+response to work from. clientInfo is
sanitized to printable ASCII, truncated to 128 chars.
