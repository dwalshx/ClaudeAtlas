<objective>
Add a versioned catalog-composition snapshot job to the daily pipeline. A new
`scripts/snapshot-catalog.js` reads the FINAL post-enrich catalog NDJSON files
(`data/skills.ndjson`, `data/plugins.ndjson`, `data/mcp-servers.ndjson`) and
writes a single bounded JSON object to `data/snapshots/YYYY-MM-DD.json`. This
compounding daily time-series powers AEO "State of Claude Skills" trend content.

catalog composition (tier mix, entity-type mix, per-category counts, growth,
maintenance health, creator count, churn) — a natural sibling to the existing
`data/pipeline-stats.json` and `data/history/` sidecars.

Output: `scripts/snapshot-catalog.js`, `scripts/snapshot-catalog.test.js`, a
`check-banned-patterns.js` allowlist entry, and a new daily-scrape.yml step +
commit-back line.

filtering, or rendering code. Only a new script, a new test, one allowlist
entry, and workflow wiring.
