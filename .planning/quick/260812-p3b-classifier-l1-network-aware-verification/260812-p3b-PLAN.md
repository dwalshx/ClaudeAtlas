<objective>
Upgrade `worker/classify.js` from v0 (trusts surface signals) to L1 network-aware
classification per `docs/agent-analytics-research/04-detection-sota.md` §7 (L1 + L2).
Production data (2026-08-12) proved two false-positive classes:

(A) IMPERSONATION — credential scanners sending a known-agent UA (ChatGPT-User,
GPTBot, MistralAI-User, …) from the WRONG network (e.g. "OpenAI" from Google
Cloud AS396982 hitting /web/.env; "Mistral" from Cloudflare's ASN hitting
/service_account.json), rotating operator daily.

(B) FALSE HUMANS — a headless-Chrome scraper farm (Kingsoft Cloud / Singapore,
~5.9k/24h) sending coherent browser headers from a datacenter, currently labeled
class='human' because header coherence alone can't see the network.

Both share one root cause: the classifier never checks the NETWORK (ASN /
asOrganization). This plan adds that layer, entirely additive and inside the
existing non-blocking `ctx.waitUntil` logging path.

Purpose: make the agent-analytics numbers trustworthy by separating spoofed
agent UAs and datacenter "browsers" from real actors.
Output: a pure `worker/asn-class.js` network module, an upgraded network-aware
`classify.js`, wired logging with an optional `asn_class` analytics column, and
docs recording the findings.
</objective>
