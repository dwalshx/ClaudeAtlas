**Classifier v0 spec (planning context + research §3 L1/L2):**

Input: `{ userAgent, asn, asOrg, accept, secFetchMode, secFetchSite, secFetchDest, secChUa, signatureAgent }` (all nullable — a plain signals object, NOT a Request, so it unit-tests trivially).

Output: `{ class, operator, confidence, method }` where class ∈ `human | agent | crawler | automated_unknown | unknown`.

Decision order (first match wins):
1. **UA list — agents** (user/task-triggered): `ChatGPT-User`, `Claude-User`, `Perplexity-User`, `MistralAI-User`, `claude-code/` prefix → `agent`, operator = openai / anthropic / perplexity / mistral / anthropic-claude-code, confidence 0.9, method `ua_list`.
2. **UA list — crawlers**: `GPTBot`, `OAI-SearchBot`, `ClaudeBot`, `Claude-SearchBot`, `PerplexityBot`, `Bytespider`, `meta-externalagent`, `Amazonbot`, `Applebot` (+ `Applebot-Extended`), `Googlebot`/`Google-Extended`/`GoogleOther`, `bingbot`, `DataForSeoBot`, `SemrushBot`, `AhrefsBot`, `PetalBot` → `crawler`, operator per list, confidence 0.9, method `ua_list`. NOTE: `Claude-User` must be checked before `ClaudeBot`-style substring logic can't confuse them — order agent list before crawler list and use word-ish matching.
3. **UA list — generic automation**: `python-requests`, `python-httpx`, `aiohttp`, `axios`, `node-fetch`, `undici`, `Go-http-client`, `okhttp`, `Scrapy`, `curl`, `Wget`, `HeadlessChrome` → `automated_unknown`, operator null, confidence 0.8, method `ua_list`.
4. **Empty/missing UA** → `automated_unknown`, confidence 0.7, method `no_ua`.
5. **Browser-shaped UA** (`Mozilla/` prefix), then coherence + ASN:
   - Sec-Fetch coherence: modern Chromium/Firefox/Safari UAs send `sec-fetch-mode`/`sec-fetch-site`/`sec-fetch-dest`. Compute `secFetchCoherent`: `1` if present, `0` if a Chromium-≥80-claiming UA lacks them (contradiction — the Browser Use signature, research §3 L2), `null` if not applicable.
   - Datacenter ASN heuristic: ASN in a known-cloud set (16509/14618 AWS, 8075 Azure, 16276 OVH, 24940 Hetzner, 14061 DigitalOcean, 63949 Linode/Akamai, 20473 Vultr, 45102 Alibaba, 132203 Tencent, 31898 Oracle — for Google Cloud match `asOrg` `/google cloud/i`, NOT plain "google", which would catch Googlebot's org) OR `asOrg` matching `/hosting|datacenter|data center|colo|server/i`.
   - Browser UA + datacenter ASN → `automated_unknown`, confidence 0.7, method `asn_heuristic`.
   - Browser UA + `secFetchCoherent === 0` → `automated_unknown`, confidence 0.6, method `coherence`.
   - Browser UA + `secFetchCoherent === 1` + non-datacenter ASN → `human`, confidence 0.7, method `coherence`.
   - Otherwise → `unknown`, confidence 0.5, method `default`. **Never default to human** — the measured 30-39% failure mode of binary classifiers (research §TL;DR-7).
6. Anything else → `unknown`, confidence 0.3, method `default`.

Also export the UA tables (`AGENT_UA_PATTERNS`, `CRAWLER_UA_PATTERNS`, `AUTOMATION_UA_PATTERNS`, `DATACENTER_ASNS`) so tests can assert coverage.
